# Локальный старт

Команды ниже вводят в PowerShell. WSL уже установлен, его не переустанавливают: `wsl --install` и `wsl --unregister` не запускать. Рабочая копия проекта — `~/POTOK` внутри Ubuntu.

Postgres другого проекта уже слушает `127.0.0.1:5432`. Его не останавливают. База «Потока» — только `potok`.

## Миграции

```powershell
wsl -e bash -lc "cd ~/POTOK && bash scripts/migrate.sh"
```

Скрипт читает `backend/.env` и применяет миграции к базе `potok`. Другие базы не меняет.

## Сайт и API

```powershell
wsl -e bash -lc "cd ~/POTOK && bash scripts/dev.sh"
```

Окно не закрывать.

- Сайт: `http://127.0.0.1:5173/`
- Схема API: `http://127.0.0.1:8000/api/docs`

Если порт занят, скрипт чужой процесс не убивает: API переходит на `8001`, страница на `5174`. Остановка — Ctrl+C в этом окне. Останавливаются только процессы, которые запустил скрипт.
